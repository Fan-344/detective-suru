## 1. 核心概念

玩家是一支手機裡的 AI 助理，名字叫 Suru，是最新一代的 AI 助理，能操作手機上的 App、替用戶處理日常瑣事（名字是產品本來的名字，不是主人取的）。主人出事沒有回來，Suru 只能看手機裡的資料、用主人的帳號傳訊息，要在兇手察覺之前找出是誰下的手。

- **平台**：手機直式，網頁可玩，匿名發行，與任何現有頻道和品牌無關
- **類型**：本格推理。線索全部公平呈現，真相唯一
- **開發方式**：一人加 AI。對話用寫好的劇本，不即時呼叫模型
- **敘事結構**：真相固定、過程自由、結局數種

### 前提成立的三個條件

「假裝被害人沒事」要說得通，每個案子都必須同時滿足：

1. 被害人不知道是誰下的手（背後偷襲或間接手法）
2. 兇手沒有確認結果，事後也查不到
3. 外界還不知道被害人的狀況

這樣兇手看到訊息時才會陷入「失敗了嗎、她知道是我嗎」的狀態，他為了確認而做的試探，就是破綻的來源。

### 主角是 AI 助理的理由

- 只看得到手機裡的東西：玩家知道的和主角知道的完全一樣，公平性變成設定的一部分
- 平常就在替主人回訊息：模仿她的語氣合情合理
- 沒有身體：不能去現場，只能靠紀錄推理

### 寫案件時的檢查項目（不對玩家明示）

本案的核心原則：**東西在誰手上，誰就到過現場。**

## 2. 定位與對手

這款遊戲寫給覺得《翻手機》太簡單的人，重心放在「冒充」，調查是手段。宣傳和開場第一分鐘都要是：你在假扮一個人，而有人正在測試你。

### 別人沒有的三件事

1. 機主還活著，兇手不知道自己有沒有得手，所以會反過來試探你。同類作品都是事情已經發生、玩家事後調查
2. 玩家就是助理本身，不是撿到手機的人
3. 本格結構：公平線索、唯一解、四格一次交卷的指認、有會讓人指錯的陷阱

### 每次試玩都要問的三個問題

1. 玩家有沒有卡住、需要停下來想的地方
2. 有沒有人指錯兇手
3. 兩個人玩的過程是否不一樣

三題有任何一題的答案是「沒有」，代表遊戲滑回「線性地聽故事」。

## 3. 玩法規則

玩家先翻手機蒐集資料，把在意的地方變成疑點，拿疑點去問人，最後指認兇手並決定把證據交給誰。全程沒有幫手。

### 兩種動作

1. **蒐集**：翻各個 App 和聊天室。看過的東西如果有時間、而且是事實，會自動排進時間軸
2. **問人**：選一張疑點、選一個對象，送出一句以晴口氣的話。同一張疑點對同一個人只能問一次，每問一次都耗電

對方的反應分三種：一頭霧水（無辜）、接得上話（他知道這件事）、迴避或反問（他在意這件事）。

### Suru App：疑點與時間軸

Suru App 只有兩個分頁：疑點、時間軸。沒有獨立的線索頁，也不用拖曳比對。

- **在意的地方 → 疑點**：玩家看過相關的東西，Suru 會多一張「在意的地方」，直接顯示那張發票、那張照片或那則訊息，問一題（哪裡讓你在意、跟哪一筆紀錄對不上）。答對了翻成疑點。每一張疑點都走這條路，沒有例外（細節見第 6 節）
- **提示**：助理不主動跳出來說話。玩家卡住時自己在卡片上按「提示」，每張三句，按一次給一句、耗一點電：先提疑問、再指向哪一類資料、最後點名哪一筆。只提問、不下結論
- **時間軸**：目的是對每個人的行蹤。只放事實（紀錄上有的，以及問出來而且有佐證的），不放說法；只顯示大概時段，先後順序照實際時間排。開局就有四列：以晴送修手機、送醫、轉入加護病房、Suru 被喚醒。其餘要玩家看過對應的東西才出現

### 三種資訊

| 種類 | 例子 | 處理方式 |
| --- | --- | --- |
| 紀錄 | 發票、天氣、通話時間、醫院簡訊、裝置定位 | 直接採信 |
| 說法 | 聊天訊息、限時動態、群組發言 | 拿紀錄來對 |
| 推論 | 兩杯咖啡代表有人同行 | 玩家回答「在意的地方」時自己完成 |

### 電量與壓力

- 不用時間系統，用手機的電量。手機在維修店架上沒插電，電量歸零前要破案
- 沒有充電，沒有省電模式
- 急迫感由兇手提供，電量是硬性上限
- 不顯示警覺量表，玩家看到的就是對方的行為

起始電量 64%。只有玩家主動做的事扣電，回覆別人傳來的訊息不扣電：

| 動作 | 扣多少 |
| --- | --- |
| 第一次打開一個 App、第一次讀一個聊天室 | 1% |
| 第一次打開背景 App | 0.2% |
| 用找裝置定位 | 4% |
| 拿疑點問人 | 2% |
| 按一次提示 | 1% |
| 在意的地方指錯一次 | 1% |
| 指認被退回一次 | 2% |
| 來電放著響完／掛斷 | 3%／1% |
| 回覆訊息、看照片、滑動、填指認表 | 不扣 |

這組數字的壓力偏低（見第 9 節）。

### 四條階梯

每個人有自己在意的事，狀態升高就會採取下一步行動。四條深淺不同，玩家的每句話都在調整這四個人的狀態。

| 人物 | 深度 | 驅動他的事 | 階梯 |
| --- | --- | --- | --- |
| 靖雯 | 深 | 以晴記得多少 | 試探、說要探望、按門鈴、登入帳號、拜託品妤查醫院、查到醫院 |
| 阿澤 | 中 | 愧疚 | 迴避、試探她有沒有生氣、向以晴坦白或向靖雯通風報信 |
| 宗翰 | 淺 | 押金會不會被講出去 | 私訊問候、試探她記得多少、在群組帶風向 |
| 品妤 | 淺 | 擔心 | 傳訊息、打電話、說要過去、連環來電 |

- 階梯只靠兩件事推進：玩家說了什麼，以及已讀不回。電量掉多少不會讓任何人升級，電量只當上限。
  - **玩家說了什麼**：每個回覆和試探各有升降。
  - **已讀不回**：玩家打開某人的聊天室、看到他等回的訊息卻沒回就離開。再做 2 個動作他會追問一句；做滿 4 個動作還是不回，他升一級。同一則訊息最多只追問一次、只讓他升一級，要等他傳了新的一則、玩家又讀了沒回才重新算。沒打開過的聊天室不會觸發，因為對方看不到已讀。
  - 每個人只有最新的一則訊息能回。他傳了新的，舊的就不能再回。
- 有幾級設了門檻，避免對方只因為被冷落就把事情講出來：
  - 靖雯的登入（第 4 級）：玩家要理過她本人（回過她的訊息或拿疑點問過她；開局的掩護說法不算），否則她停在第 3 級
  - 阿澤的第 3 級：玩家要私訊過他。到了第 3 級，他如果已經覺得事情不對就向以晴坦白，否則去跟靖雯通風報信（靖雯升一級）。讓他覺得不對的方法：問過他「iPad 被帶走了？」或「iPad 裡的東西？」、問出靖雯那晚來過工作室，或問他「你知道我那天後來怎麼了嗎」
  - 宗翰的第 2 級：玩家要先拿押金確認單問過他
- 有些東西只在某一級才會出現（例如登入確認視窗留下的那筆位置紀錄），但破案需要的東西都不靠這些
- 狀態降得很低時對方會鬆懈、話變多，反而講出不該講的細節
- 狀態從手機本身的訊號看出來：已讀後多久才回、「正在輸入」出現又消失、訊息變短、平常每天發限動的人突然停更
- 靖雯查到醫院就是遊戲結束

### 各人的階梯細節

**靖雯**（6 級）：私訊試探「那週三還約嗎」→ 說要帶吃的來探望 → 到樓下按門鈴沒人應 → 登入確認視窗 → 拜託品妤查醫院 → 查到醫院（結局）。會讓她升級的事：回她訊息時選了讓她起疑的那句；拿疑點問她（「iPad 被帶走了？」「iPad 裡的東西？」各升兩級，其餘升一級）；在群組拿「iPad 被帶走了？」問宗翰（她看得到，升一級）；阿澤通風報信；已讀不回。

**阿澤**（3 級）：簡短問候 →「你是不是在生我的氣」（他已經承認見面的話不說這句）→ 坦白或通風報信。承認見面本身不讓他升級，升不升看玩家接著回哪一句。

**宗翰**（3 級）：問候、說可以幫忙開門 → 私訊試探「週六晚上我講話比較急……那天的事，妳現在還記得多少？」→ 在群組帶風向：先交代自己九點五十就走、那時她人好好的，再提樓梯陡、下雨、她一個人搬到那麼晚，請大家別急著下結論。靖雯附和「那個樓梯真的很陡 我以前也差點滑倒」，品妤（還理人時）追問，阿澤回「？」。宗翰從頭到尾不認押金，也不還錢；被確認單質問時說那是制式表單、金額後來有變動、當面再談。他要到被指認之後才認。

**品妤**（4 級）：連問身體狀況 → 打電話來 → 說下班直接過去 → 先警告「妳再不回我就一直打」，然後連環來電。

### 來電

- 來電會跳出來電畫面。Suru 不能說話，所以只能掛斷，或放著讓它響完；響的時候不能做別的事
- 掛斷：對方馬上知道被按掉。響完：電話 App 多一筆未接來電，扣的電比較多
- 連環來電每隔 2 個動作打一通，每通都扣電，要在私訊裡回她才會停。三種回法：
  - 「不要再打了」：她繼續打
  - 拜託她先別打、之後一定解釋：她停手，變成自己人。之後靖雯來找她查醫院時她會擋掉一次，靖雯退一級（只有一次）
  - 坦白「我不是以晴 我是她手機裡的 AI 助理」：她不相信，覺得被離譜的謊話敷衍，整局不再理人。之後問她任何事都只有已讀，靖雯找她查醫院時玩家也攔不到。破案不會卡住，因為指認需要的東西都不經過她

### 不會卡死的設計

- 主線上每個結論至少有兩條路能到，最關鍵的給三條以上
- 要靠對話才拿得到的線索，另備一條靜態路徑
- 指認需要的四張疑點，都能只靠翻手機拿到，不需要任何人配合
- 最後把拼圖接起來的那一步不重複佈線，留給玩家
- 決定性的對照一定跨 App，另放幾個沒有線索的 App 當背景

## 5. 第一案：真相與時間軸

那台舊 iPad 一直放在舊家。以晴週五找到它，週六晚上回去拿。靖雯本來只想在週三前把它偷走，但她沒有鑰匙進不了屋；看到以晴抱著 iPad 走出來的那一瞬間，從背後把她推下樓梯，拿走 iPad。以晴昏迷送醫，不知道有人來過。

有一件事是靠紀錄證明的：iPad 是在她摔倒之後才被帶走的。找裝置的位置紀錄顯示它 22:41 才離開永和，而她 23:12 已經到院。所以不可能是她自己下午把 iPad 帶去大安。

## 7. 結局

### 指認兇手

Suru App 裡隨時可以進「指認兇手」。地點和手法不是謎，由 Suru 開頭直接講明：

> 週六晚上，以晴在永和舊家四樓往三樓的樓梯間，被人從樓梯上推了下去。
> 她帶在身上的 iPad 不見了。

玩家填四格，全部填好才能交出去；交出去之前可以隨意換，填的時候不提示對錯，手上任何一張翻開的疑點都放得進任何一格。

| 格子 | 題目 | 算對的疑點 |
| --- | --- | --- |
| 時間 | 她是什麼時候出事的？ | 22:07 還在買東西？／iPad 被帶走了？ |
| 動機 | 兇手為什麼要這麼做？ | iPad 裡的東西？ |
| 不在場證明 | 兇手的不在場證明，哪裡是假的？ | 台中的夜市？ |
| 是誰 | 兇手是誰？ | 靖雯 |

「躲在通往頂樓的樓梯、從背後推」和在場證明的完整推論不要求玩家證明，寫在結局文字和解答篇裡。

### 判定規則

| 情況 | 結果 |
| --- | --- |
| 指認的不是靖雯 | 直接進指錯人的結局。看完可以回到指認之前 |
| 指認靖雯，但有格子放錯 | 進「站不住」結局：一樣傳進群組，靖雯針對放錯的那幾格反駁（放錯幾格就出現幾句），沒有人拿得出別的東西。不退回、不扣電。看完可以回到指認之前，格子的內容保留 |
| 指認靖雯，三格全對 | 選把證據交給誰，進入下表的結局 |

登入確認視窗的紀錄不是必要的。四張需要的疑點都能只靠翻手機拿到，所以不跟任何人說話也能破案；跟人說話換來的是更有把握的指認，以及不同的結局。

### 交給誰

| 對象 | 結果 |
| --- | --- |
| 品妤 | 乾淨的破案。她這時才知道宗翰連她的押金也拿了 |
| 品妤（之前坦白過是 AI、她不理人了） | 她這次相信了，收回那天罵的話 |
| 宗翰 | 案子破了。他自己決定把押金確認單從證據裡拿掉，說是怕模糊焦點；報案後在群組把功勞攬在身上，品妤還不知情地謝他 |
| 阿澤（已經讓他覺得事情不對） | 他先拍下櫃子裡的 iPad 和列印稿傳過來、承認行程是他講出去的，然後說要陪她去自首。她答應了，隔天帶著東西消失。他一個人去派出所，手上還有那張照片 |

### 群組對峙（交給品妤的結局）

把證據交給品妤是最完整的破案，寫成推理劇的收尾：品妤先向醫院確認，然後由她在「永和四樓」群組開口，把 Suru 查到的東西一筆一筆攤開。Suru 不在群組現身。

- 順序：品妤引言（以晴在加護病房、這幾天回訊息的是她的手機）→ 宗翰要依據 → 夜市動態對上台中的雨 → iPad 的位置 → 阿澤說出能進工作室的是靖雯、她那晚淋濕了來 → 靖雯說可能是以晴自己拿去的 → 23:12 她已在急診 → 靖雯承認
- 靖雯承認時說的是設定裡的事：只想把 iPad 拿走、沒有鑰匙、在樓梯上等、看到以晴抱著它走出來
- 後續行動：品妤報警並去醫院陪她；阿澤把 iPad 和列印稿帶到派出所，承認行程是他講出去的；宗翰沉默，三天後把四個人的押金轉回去；靖雯退出群組
- 之前對品妤坦白過是 AI 的話，開頭和最後一則訊息不同（她收回那天罵的話）
- 證據交出去、品妤回了最後一則訊息之後，手機就沒電了。群組對峙和後續行動是「這支手機沒有看到」的事，最後一句是幾天後有人到維修店把手機領走、插上電
- 交給宗翰、交給阿澤的結局沒有對峙場面，但收尾的結構一樣：交出證據 → 對方回了訊息 → 電量 1%、螢幕暗下 → 「接下來的事，這支手機沒有看到」→ 各自的後續 → 幾天後有人到維修店把手機領走、插上電。交給阿澤的兩個結局都是靖雯跑了：他不是不信要當面問她，就是想陪她去自首，兩種都替她爭取到時間。差別在他有沒有先留下那張照片
- 不另外做解答篇。試過敘事版和調查報告版，都拿掉了

### 指錯人之後

指錯人的結局看完，玩家有三個選擇（參考 Sherlock Holmes: Crimes & Punishments 的做法，把要不要揭曉交給玩家）：

- **回到指認之前**：回到交卷前那一刻，電量、已翻開的疑點、每個人的狀態都照舊，可以繼續找、再指認一次。不扣電：指認本身不花電，花電的是蒐集，扣電只會罰到漏看線索的人
- **我想知道真相**：先確認一次（看了就沒有重玩的樂趣），再顯示已經寫好的破案結局「交給品妤」（品妤在群組對峙的那一個）。不另外寫一份真相
- **重新開始**

破案的結局看完，以及看完「真相」之後，一樣給「回到指認之前」和「重新開始」。破案後回到指認之前，可以改交給另一個人，看別的結局，不用重玩。

破案時顯示這是第幾次指認、還剩多少電，讓一次指對有價值，但不扣任何東西。指認的說明從「人指錯了，就沒有第二次機會」改成「人指錯了，事情就會照錯的方向走下去」。

沒電和被查到醫院的結局，回到前一刻沒有用，先只給重新開始；要不要做中途的存檔點，等試玩後再決定。

### 其他結局

- **指錯人**：指向宗翰、阿澤或品妤，各有一段。指錯時不會選交給誰，Suru 直接把東西傳進群組，表明自己是她的手機並點名
  - 只寫玩家本來就知道的事：被指的人否認（只是他的說法）、其他人的反應、這個指認沒有結果、手機沒電、幾天後被領走
  - 不寫任何玩家可能還沒找到的東西：不在場證明的細節、被指的人承認別的事（押金、見過面）、靖雯事後做了什麼、iPad 的去向，也不放指向特定人的問句。理由是指錯之後可以回到指認之前，結局如果把疑點講出來，等於替玩家破案
  - 讓玩家知道指錯了，只靠一句不指名的旁白：「群組安靜了下來。四個人裡，有一個人鬆了一口氣。」
- **靖雯查到醫院**：她的階梯走到最後一級
- **沒電**：電量歸零

### 登入確認視窗

有人在別的裝置輸入以晴的帳號密碼時，這支手機會跳出登入確認視窗，附一張小地圖，寫著位置在台北市大安區附近。位置本身是線索，因為靖雯自稱在台中。

- 兩個入口，整局只出現一次：靖雯的階梯走到第 4 級；或玩家在群組拿「iPad 被帶走了？」問宗翰（靖雯看到以晴開始找 iPad，急著登入）
- 按「不允許」：對方立刻知道這支手機有人在操作，靖雯升一級
- 按「允許」：不會放行，只跳出一句提醒（問句），視窗不關、不扣電
- 點視窗外面不處理：她無法確定，等級不變
- 視窗出現後，會留下一筆登入紀錄（位置在大安區）

驗證會送到這支手機，所以她不可能登入成功。這個事件是壓力和一筆佐證，不是倒數，也不是破案必需。
