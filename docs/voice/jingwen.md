# 靖雯｜語氣指南

狀態：已確認（2026-11-14）。

30 歲，小說家。規格已定的部分：一次好幾則短訊、帶表情符號、叫以晴「晴」。

最重要的一條：她的訊息**不能比別人突出**。她是五個人裡最會聊天、最讓人舒服的那個，所有試探都包在關心裡。

## 規則

- **長短**：每則都短，但一次連發三到四則，把一句話拆開傳
- **標點**：愛用「～」和「！！」。問句會打問號，或用「呀」「嘛」收尾
- **表情符號**：幾乎每一串的最後一則都有。常用 🥺 😂 🫶 💪
- **語助詞**：嘛、啦、齁、呀。聽起來在撒嬌
- **稱呼**：叫以晴「晴」，常拉長成「晴～～」
- **你／妳**：打「妳」
- **髒話**：不說，也不用粗的詞
- **問問題的方式**：從不直接問。先講自己的事，再順口帶到她想知道的事，最後補一句「沒事啦」

## 壓力下的變化

階梯每升一級，以下特徵依序出現。玩家看不到數字，只看得到這些：

1. 表情符號變少，從每串都有變成偶爾
2. 「～」消失
3. 連發變成單則
4. 問題變得具體，開始問時間和地點
5. 已讀後隔很久才回，或「正在輸入」出現又消失
6. 完全不帶語助詞，句子變得很平

鬆懈的時候相反：話變多、連發變長、會主動講自己那幾天做了什麼。

## 範例

1. 晴～～
2. 妳在忙嗎🥺
3. 我跟妳說！！／今天編輯又改我稿／我真的會氣死
4. 沒事啦 就想妳了嘛🫶
5. 妳有好好吃飯嗎／不要又只喝咖啡齁
6. 天啊太可愛了吧😂😂
7. 那我們再約嘛～／我都可以 看妳
8. 欸對了／妳上次說的那個／後來怎麼樣了呀
9. 好啦不吵妳 妳先忙💪
10. 愛妳🫶

## 跟品妤的區別

兩個人都會連發，容易混。分法：

| | 靖雯 | 品妤 |
| --- | --- | --- |
| 表情符號 | 有 | 沒有 |
| 粗話 | 不說 | 會說 |
| 句子 | 完整、修過 | 想到就傳、有錯字不改 |
| 關心的方式 | 問妳好不好 | 罵妳怎麼不回 |
