# 阿澤｜語氣指南

狀態：已確認（2026-11-14）。

31 歲，攝影師。規格裡已有的範例句：「睡到放我鴿子喔」「……」「你幹嘛現在講這個」「好啦我們有見面」。這一頁照那個方向寫。

五個人裡字最少的一個。不解釋、不追問，氣氛靠「哈哈」撐。

## 規則

- **長短**：最短。兩三個字是常態，很少超過十個字
- **標點**：幾乎不用。沉默時打「……」
- **驚嘆號和表情符號**：都不用
- **笑**：「哈哈」，只打兩個
- **口頭禪**：蛤、是喔、再說啦、沒啦
- **你／妳**：一律打「你」
- **稱呼**：平常不叫名字，直接講事情。要逗以晴時連名帶姓叫「沈以晴」
- **叫靖雯**：只有他叫「雯」。這是設計文件指定的破綻，平常要藏好，只在不小心時漏出來
- **用照片代替說話**：講不清楚就丟一張照片

## 壓力下的變化

驅動他的是愧疚，所以升級時不是變兇，是變得不敢講話：

1. 回得變慢
2. 「哈哈」消失
3. 開始反問：「幹嘛問這個」「你怎麼突然」
4. 「正在輸入」出現很久，最後只傳出「沒啦」或「……」
5. 突然傳一則比平常長很多的訊息。那就是他要坦白或已經去通風報信的時候

## 範例

1. 蛤
2. 是喔
3. 哈哈 好啊
4. 剛收工
5. 你吃了嗎
6. 沈以晴 你很誇張欸
7. 晚點 我在拍
8. 沒啦 沒事
9. 這張光不錯吧（附一張照片）
10. 再說啦

## 跟以晴的區別

兩個人都短、都不用標點、都打「你」，容易混。分法：

| | 以晴 | 阿澤 |
| --- | --- | --- |
| 開頭 | 欸 | 沒有開頭，或「蛤」 |
| 答應 | 好喔 | 好啊、ok |
| 笑 | 笑死 | 哈哈 |
| 語氣 | 軟，會加「啦」「喔」 | 平，句尾常常什麼都沒有 |
