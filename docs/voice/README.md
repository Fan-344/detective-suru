# 語氣指南｜總則

狀態：已確認（2026-11-14）。

每個角色一頁：[以晴](yiqing.md)、[靖雯](jingwen.md)、[阿澤](aze.md)、[宗翰](zonghan.md)、[品妤](pinyu.md)。

範例句只用來定語氣，內容都是日常瑣事，不是遊戲裡會出現的台詞，也不帶任何案件資訊。範例裡的「／」表示分成好幾則傳。

## 一眼分辨表

遮掉名字時，靠這張表就該分得出來。

| | 以晴 | 靖雯 | 阿澤 | 宗翰 | 品妤 |
| --- | --- | --- | --- | --- | --- |
| 一則多長 | 很短 | 短，但一次連發三四則 | 最短，常常兩三個字 | 最長，一則講完 | 短，連發，想到就傳 |
| 標點 | 不用，以空格斷句 | 「～」「！！」和問號 | 幾乎不用 | 逗號句號都打 | 「？？？」和一長串「哈」 |
| 驚嘆號 | 從來不用 | 常用 | 不用 | 偶爾 | 常用 |
| 表情符號 | 不用，只傳貓貼圖 | 幾乎每串都有 | 不用 | 只用 🙏 和 😅 | 不用，傳貼圖 |
| 笑的時候 | 笑死 | 😂😂 | 哈哈 | 哈哈， | 哈哈哈哈哈哈哈 |
| 口頭禪 | 欸、好喔 | 嘛、啦、齁、呀 | 蛤、是喔、再說啦 | 這部分、再麻煩、OK的 | 吼唷、蛤、是在哈囉 |
| 你／妳 | 你 | 妳 | 你 | 妳 | 妳 |
| 怎麼叫以晴 | — | 晴 | 不叫，逗她時連名帶姓 | 以晴 | 阿晴 |

## 以晴怎麼叫他們

設計文件只寫「叫朋友綽號」，以下是確認過的綽號：

| 對象 | 以晴叫他 | 理由 |
| --- | --- | --- |
| 靖雯 | 靖 | 跟靖雯叫她「晴」成對，大學一起做小誌的兩個人。也讓阿澤叫的「雯」顯得跟所有人都不一樣 |
| 阿澤 | 阿澤 | 本來就是綽號 |
| 宗翰 | 翰哥 | 年紀最大，當年的簽約人 |
| 品妤 | 阿妤 | 跟品妤叫她「阿晴」成對 |

宗翰和品妤叫靖雯都叫「靖雯」。全場只有阿澤會叫「雯」。

## 用語

用台灣人傳訊息的口氣。下列中國用語不出現，右邊是替代：

| 不用 | 改用 |
| --- | --- |
| 視頻、短視頻 | 影片、限動 |
| 信息、短信 | 訊息、簡訊 |
| 靠譜、給力 | 可靠、厲害 |
| 質量 | 品質 |
| 小夥伴、親 | 朋友、大家 |
| 沒毛病、牛、絕絕子、我真的會謝 | 不用，沒有替代 |
| 打車、外賣、地鐵 | 叫車、外送、捷運 |
| 屏幕、充電寶、U盤 | 螢幕、行動電源、隨身碟 |
| 立馬、估計、挺好的 | 馬上、應該、蠻好的 |
| 早上好、晚上好 | 早安、晚安 |

## 驗收用的盲測

文本寫完後，從四個人的訊息裡各抽十句、遮掉名字、打亂順序，看讀的人能不能分對。目標是四十句裡錯不超過四句。

## 已確認的項目

1. 一眼分辨表裡每個人的特徵
2. 四個綽號
3. 「你／妳」的分法：以晴和阿澤一律打「你」，其他三人打「妳」
4. 各頁「壓力下的變化」，這會直接變成階梯升級時玩家看到的訊號
