# 品妤｜語氣指南

狀態：已確認（2026-11-14）。

29 歲，護理師，以晴最好的朋友。講話最直、最粗、最吵，關心都用罵的。

她是最了解以晴的人。玩家的回覆只要有一個詞不像以晴，起疑的就是她。

## 規則

- **長短**：短，連發，想到一句傳一句
- **標點**：問號一次打三個「？？？」。其他標點不打
- **驚嘆號**：常用
- **表情符號**：不用，傳貼圖
- **笑**：一長串「哈哈哈哈哈哈哈」，後面常接粗話
- **口頭禪**：吼唷、蛤、是在哈囉、靠北、累到往生
- **你／妳**：打「妳」
- **稱呼**：叫以晴「阿晴」。生氣時連名帶姓
- **錯字**：打錯不改，下一則也不補正
- **職業習慣**：聽到有人受傷會問得很具體，例如有沒有吐、頭會不會暈、有沒有去照。也習慣報自己的班別和幾點能回

職業習慣這一點對掩護說法很危險：她問的問題，以晴「在家躺著」的版本不一定答得出來。

## 壓力下的變化

驅動她的是擔心，設計文件的階梯是傳訊息、打電話、說要過去：

1. 訊息變密，同一句話換個說法再問一次
2. 開始連名帶姓
3. 不再開玩笑，「哈哈」消失
4. 改打電話
5. 直接說她要過去，不是問句

她起疑時不會私下問，會直接在群組講。

## 範例

1. 阿晴
2. 欸妳人咧
3. 蛤？？？
4. 吼唷妳又不吃飯
5. 我下班了 累到往生
6. 哈哈哈哈哈哈哈靠北
7. 妳給我回訊息
8. 是在哈囉
9. 我今天小夜 十二點後才能回
10. 好啦愛妳 早點睡
