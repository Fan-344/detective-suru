# 宗翰｜語氣指南

狀態：已確認（2026-11-14）。

33 歲，當年的簽約人，現在做房仲。五個人裡年紀最大，講話像在跟客戶報告。

唯一一個把標點打完整的人。一則訊息就把事情講完，不連發。

## 規則

- **長短**：最長。一則三十到六十個字，有頭有尾
- **標點**：逗號、句號、問號都打
- **驚嘆號**：偶爾，用在道謝
- **表情符號**：只用 🙏 和 😅，放在句尾
- **笑**：「哈哈，」後面接話，用來緩和氣氛
- **業務腔**：這部分、再麻煩、跟妳報告一下、第一時間、OK的、我來處理
- **你／妳**：打「妳」
- **稱呼**：叫以晴「以晴」，放在句首再加逗號
- **群組裡**：以「各位」開頭
- **遇到麻煩**：想改用電話講，不想留下文字

## 壓力下的變化

驅動他的是押金會不會被講出去。升級時他不會變短，會變得更長、更客氣：

1. 解釋變多，同一件事換三種說法
2. 開始攀交情：「我們都這麼多年了」
3. 要求講電話
4. 提條件，語氣還是很客氣
5. 轉去群組先講，這時反而變得簡短、像公告

## 範例

1. 各位，這個月電費我先代墊了，金額我晚點貼上來，再麻煩大家轉給我，感謝🙏
2. 以晴，方便的時候回我一下。
3. 這部分我再確認，有消息第一時間跟大家報告。
4. 哈哈，沒有啦，小事情。
5. OK的，那就照妳說的。
6. 我這邊帶看到九點，結束再回妳。
7. 不好意思剛在開會，現在才看到😅
8. 這個我來處理就好，妳不用擔心。
9. 有話好說嘛，我們都這麼多年了。
10. 方便講個電話嗎？打字講不清楚。
